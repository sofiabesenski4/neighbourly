# Security Policy

Neighbourly Resources helps people find shelter and community services. Many of our users are in vulnerable situations, so we take reports seriously.

## Reporting a Vulnerability

Please report vulnerabilities privately by email to **neighbourlyresources@proton.me**.

Do not open a public GitHub issue or pull request for a security problem.

Please include:

- What the issue is and where it lives in the code.
- Steps to reproduce it.
- The impact you think it has.

We will acknowledge your report, keep you updated, and credit you in the fix if you would like.

## Supported Versions

Only the `main` branch is supported. Fixes are not backported.

## Guidelines

- Only test against your own local copy of the app.
- Do not access, change, or delete data that belongs to other people.
- Do not run denial of service or spam tests against a live deployment.
- Give us reasonable time to fix the issue before sharing it publicly.

## Out of Scope

- Vulnerabilities in third-party services we use, such as OpenAI or Anthropic. Please report those to the provider.
- Findings from automated scanners without a working proof of concept.
- Social engineering.
